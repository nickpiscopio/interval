# 47. Standardize All Bottom Sheets on @gorhom/bottom-sheet

We decided to replace custom Animated/Modal slide-up sheets across the application with `@gorhom/bottom-sheet` (`BottomSheetModal` wrapped by a root `BottomSheetModalProvider` in `App.tsx`), standardizing all bottom sheets including exercise inspection ([ExerciseDetailModal.tsx](file:///Users/nickpiscopio/Documents/workarea/nick/interval/src/components/ExerciseDetailModal.tsx)), interval editing ([EditIntervalModal.tsx](file:///Users/nickpiscopio/Documents/workarea/nick/interval/src/components/EditIntervalModal.tsx)), and exercise catalog selection ([ExercisePickerModal.tsx](file:///Users/nickpiscopio/Documents/workarea/nick/interval/src/components/ExercisePickerModal.tsx)).

1. **Native Gesture Coordination**: Leverages `react-native-gesture-handler` and `react-native-reanimated` for 60fps animations, dynamic content sizing, and smooth backdrop interaction without JavaScript thread bottlenecks. Swipe/pan dismissal and drag handles are intentionally disabled (see ADR 0016 §6).
2. **Integrated Drill-Down & Quick-Add UX**: [ExercisePickerModal.tsx](file:///Users/nickpiscopio/Documents/workarea/nick/interval/src/components/ExercisePickerModal.tsx) provides a 1-tap `+ Add` action directly on catalog cards as well as an in-sheet drill-down view (icon-only circular back button, instructions, target muscles, and a sticky `Add to Timer` button). This avoids fragile 3-sheet nesting while giving users instant addition or deep inspection in a single bottom sheet.
3. **In-Sheet Drill-Down Navigation (Supersedes Multi-Sheet Stack Management)**: Originally configured with `stackBehavior="push"`, modal stacking when opening the library from within the interval editor has been superseded by in-sheet drill-down navigation (see ADR 0049), providing seamless single-sheet transitions with back button return.
4. **Interactive Keyboard Avoidance**: Employs `BottomSheetTextInput` in editors and search fields to automatically coordinate keyboard appearance and sheet positioning without manual padding hacks or layout jumps.
5. **Token Consistency**: Preserves full interval design system tokens (`RADIUS.lg`, `Colors.surface.card`, `SHADOWS.modal`), applied once through a shared sheet frame component.
